# Portfolio

フロントエンドエンジニア・Sekimitsu Masakiのポートフォリオサイトです。  

## サイト構成

- **MV（メインビジュアル）** … ヒーローセクション。スクロールに応じたアニメーション付き
- **About** … プロフィール、強み、できること（HP/LP制作、WordPressテーマ開発、レスポンシブ対応、React/Next.js開発）
- **Skills** … 使用言語・CMS・フレームワーク・ツール・環境
- **Works** … 制作実績（コーポレートサイト、プロダクト紹介サイト、Webアプリケーション）
- **Header / Footer** … ナビゲーションとコピーライト

## 技術スタック

- **フレームワーク**: Next.js 16 / React 19
- **言語**: TypeScript
- **スタイル**: Sass（CSS Modules）

## 開発の始め方

開発サーバーを起動します。

```bash
npm run dev
# または
yarn dev
# または
pnpm dev
# または
bun dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて表示を確認できます。

ページの編集は `src/app/page.tsx` などを行い、保存すると自動で反映されます。

## 利用スクリプト

| コマンド | 説明 |
|---------|------|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | 本番用ビルド |
| `npm run start` | 本番サーバー起動 |
| `npm run lint` | ESLint の実行 |
